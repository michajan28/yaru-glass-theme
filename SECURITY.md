# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities through GitHub's private
vulnerability reporting for this repository. Do not report them in a public
issue.

Security reports are reviewed by the repository owner and any collaborators
granted repository access. The project does not promise a response or fix
timeline.

## Supported versions

Only the latest released version is supported for security fixes. Upgrade to the
latest release before reporting an issue when practical.
