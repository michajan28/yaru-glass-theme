# Lock-Screen Demo Assets

These assets are bundled for the independent browser concept, not installed as
desktop wallpapers. They do not depict the demo's fictional profile identity.
Source pages and licensing were checked on 2026-11-02.

## Icons

The SVG files in `icons/` are unmodified [Lucide](https://lucide.dev/) icons from
[version 0.468.0](https://github.com/lucide-icons/lucide/tree/0.468.0/icons).
Their ISC license and required notice are retained in [icons/LICENSE](icons/LICENSE).

## Font

The demo loads the existing bundled Inter variable font. Its SIL Open Font License
is retained in [assets/fonts/Inter/LICENSE.txt](../../../assets/fonts/Inter/LICENSE.txt).
